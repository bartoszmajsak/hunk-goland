# Hunk Session 0.1.0

The first public version integrates upstream Hunk reviews into GoLand's code editor and diff views.

- Add line-attached or selected-range reviewer comments with Markdown, Ctrl+Enter, expandable
  conversation areas, and inline deletion confirmation.
- Read agent responses and their reply relationships, find commented files and lines, and navigate
  using the Hunk Review pane and previous/next shortcuts.
- Review working-tree changes, branch comparisons, and concrete revisions, including split,
  unified, and newly added-file diffs.
- Recover root reviewer comments after a matching IDE restart; missing agent responses and reviewer
  replies remain labeled read-only local history.

Install upstream Hunk separately, then install the plugin ZIP from GoLand's **Plugins | Install
Plugin from Disk…** menu and accept the reload/restart prompt. The tested dependency is Hunk
**0.23.0**, including automatic signed local authentication. Release verification runs on Linux against GoLand **2026.2.1.1**; other operating systems
have not been release-tested.

Comments target current/right-side lines or selected ranges inside one published Hunk hunk.
Saved-note editing, reviewer reply creation, out-of-hunk comments, and interactive TUI attach/join
are not supported by the tested integration. Hunk sessions are ephemeral; local recovery is conditional and is not a
backup. External refresh uses bounded two-second polling.

The release includes the plugin ZIP, a captured user-guide site, SHA-256 checksums, and build
metadata identifying the source commit and successful test gates. The metadata is not a signed
artifact attestation. See the guide in the documentation archive for setup and troubleshooting.
